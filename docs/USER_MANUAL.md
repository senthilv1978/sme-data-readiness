# User Manual

## Before you begin

This is a self-assessment for an SME owner, manager, technology lead, or adviser. Set aside roughly 10 minutes (the estimate should be validated in a pilot). You do not need an account. Your answers are saved in the current browser profile only.

Do not enter passwords, customer-level datasets, bank details, or sensitive personal information. On a shared device, another person using the same browser profile may be able to access the saved assessment.

## Complete the assessment

1. Select **Start free assessment**.
2. Add optional business context. The name, sector, team size, respondent role, objective and challenge fields are optional.
3. Answer each question based on how work happens today, rather than how you hope it works. Choose a score from 1 to 5, or **Not sure yet**.
4. Use **Back** to change an earlier answer. Your progress is saved locally as you go.
5. Select **See my results** at the end. You can see pillar results at any completion level; an overall score requires at least 80% of the questions to be answered.

“Not sure yet” is a valid answer. It does not count as the lowest score. It is treated as an unknown and reduces confidence in the assessment.

## Understand your results

- **Overall maturity:** weighted average of scored pillars, displayed from 0 to 100 when the completion threshold is met.
- **Five dimensions:** each pillar score, its published weight, and how many data capabilities it represents.
- **Assessment confidence:** an indicator based on response completeness and unknown answers. It is not independent evidence verification.
- **Priority risks:** separate warnings from selected governance answers. A strong overall score cannot suppress them.
- **Suggested actions:** generated only when the corresponding answer conditions are met. Expand an action to see first steps, suggested owner, success measure, dependencies and a caution.
- **Priority index:** impact × risk reduction × frequency ÷ effort. It is a planning aid, not a financial valuation; review the ordering for your context.
- **Action status:** select Not started, In progress, Blocked or Complete. Status is saved in the same browser.

Roadmap time horizons are planning estimates: immediate is 0–30 days, near term is 31–90 days, and later is 90+ days. Adjust timing to available capacity and dependencies.

## Export, print and delete

- **Export JSON** downloads a machine-readable copy of the profile, answers, result summary and suggested actions. Keep it in a location with appropriate access controls.
- **Print / save PDF** opens your browser’s print dialog. Choose **Save as PDF** to create a report. Review print preview before sharing; the PDF contains the assessment results and may contain a business name.
- **Delete data** asks for confirmation, then clears the current assessment from this browser. It does not delete exported files, printouts, browser backups, or copies in other browser profiles.

## Resume or start over

Return to the page using the same browser profile to resume. To clear all saved answers and start again, select **Delete data** on the results screen. Browser storage may also be cleared through the browser’s site data controls.

## Limitations

This is an initial self-assessment, not an audit, certification, compliance assessment, security test, or confirmation that a company is ready for AI. Scores are not external benchmarks. Seek qualified professional advice for material security, privacy, legal or regulatory concerns.
